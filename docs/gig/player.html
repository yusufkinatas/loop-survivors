The Gig captures

Nine points, 16 bars each, phrase-aligned, recorded off the master bus with no combat on the field. Same rig and same tap as docs/baseline/ and docs/palette-control/. Numbers are triggers per bar. Set a comfortable volume once and leave it — denser and louder are very easy to confuse.

Nobody authored these patterns. Every one is a set of performances, installed by step list so a capture is reproducible — see capture-rig.js for how the lists are built and why.
