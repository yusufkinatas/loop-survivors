# Pixel-art overhaul concept references

These three PNGs are **reference-only** art-direction explorations. They are
not runtime sprites, atlas inputs, or production masters. Production candidate
sprites are reconstructed deliberately on their native grids and do not crop,
key, or resize these images.

All three were generated with the built-in OpenAI image-generation tool on
2026-07-18 for this repository. No third-party source image was supplied.

## `gilded-ossuary-reference.png`

Prompt summary: a controlled top-down crypt gameplay scene with the player,
small flying enemy, humanoid, golem, spider boss, required pickup grammar,
projectile, melee, wide-area boundary, impact, HUD meter, boot icon, and reward
card. The requested language used near-black outlines, aged bone, cold cyan,
relic gold, restrained violet, upper-left light, and severe cathedral mood.

## `moonlit-tapestry-reference.png`

Prompt summary: the same controlled truth scene with broad flat clusters,
cut-paper silhouettes, deep indigo outlines, lavender rim light, dusty teal,
parchment, coral danger accents, and a dreamlike nocturnal-folklore mood.

## `arcade-reliquary-reference.png`

Prompt summary: the same controlled truth scene with very low-resolution
geometric silhouettes, bold near-black outlines, minimal interior detail,
electric cyan, hot magenta, danger orange, white collision cores, and kinetic
midnight-arcade energy.

Every prompt explicitly required a truthful size hierarchy, transparent
wide-area interior, no text, no watermark, and no blur or antialiasing. The
generator's concepts remain high-detail references; those instructions do not
make the files shippable pixel art.
